# ---------------------------------------------------------------------------
# Reel Creator Agent — dependencies
# Grouped by build step. Uncomment a group when we start that step.
# ---------------------------------------------------------------------------

# Step 1 — scaffolding / config
python-dotenv>=1.0.0

# Step 0 — topic scouting (Reddit / YouTube / Google Trends)
#   No new dependency. `requests` below does the HTTP, the trends feed is
#   parsed with stdlib xml.etree, and the phrase pass goes through step 2's
#   Gemini client. Deliberately NOT pytrends: it scrapes an internal endpoint
#   and breaks every few months, which is not a dependency worth putting under
#   a pipeline when the official RSS is published and stable.

# Step 2 — script generation (Gemini)
google-genai>=1.0.0

# Step 3 — text-to-speech (ElevenLabs)
#   Raw REST via requests instead of the `elevenlabs` SDK — one endpoint, and
#   it keeps the API's own error payload intact. mutagen reads .mp3 duration
#   from the frame headers (pure Python, no ffmpeg).
requests>=2.31.0
mutagen>=1.47.0

# Step 4 — visual sourcing (Pexels / Pixabay / Openverse)
#   `requests` above does the HTTP. Pillow measures downloaded stills: providers
#   sometimes report the original's dimensions while serving a smaller file, and
#   the 9:16 resolution floor has to be applied to what actually arrived.
Pillow>=10.0.0

#   Optional: needed only when VISUAL_PROVIDERS includes `youtube`. The Data
#   API is a catalogue and serves no media, so yt-dlp does both jobs - reading
#   the real format list (the API will not say whether an upload is 1080p or
#   4K, which is what decides whether it survives the 9:16 crop) and fetching
#   the bytes. Left commented out because the default provider list does not
#   include youtube, and this is a large dependency to carry unused.
# yt-dlp>=2024.1.0

# Step 5 — video assembly
#   Raw ffmpeg subprocess calls, not moviepy: the whole edit goes into one
#   filter_complex, which is one encode instead of moviepy's write-then-concat,
#   and burning captions in needs libass either way.
#   imageio-ffmpeg only ships the binary — it is the fallback when the machine
#   has no ffmpeg on PATH. Delete it if you install ffmpeg yourself (it must be
#   built --enable-libass, or the captions cannot be burned in).
#   Pillow (above) measures caption text so a long word can be scaled to fit.
imageio-ffmpeg>=0.4.9

#   Optional: local word-level timestamps, used when CAPTION_ALIGNMENT=whisper
#   or when the ElevenLabs alignment call fails. Pulls a model down on first
#   run; the default (ElevenLabs forced alignment) needs neither.
# faster-whisper>=1.0.0

# Step 6 — Instagram caption + hashtags
#   No new dependency: the copy goes through step 2's Gemini client
#   (`script_gen.call_gemini`) rather than a second one, and everything after
#   the call - character limits, tag hygiene, attribution - is stdlib.

# Step 7 — Telegram delivery
# python-telegram-bot>=21.0

# Step 8 — end-to-end run + daily scheduling
#   No new dependency, deliberately. The run is the six steps above called in
#   order, and the schedule is a task definition handed to Windows Task
#   Scheduler through schtasks, which is already on the machine. APScheduler
#   would add a process that has to be running to fire, and the thing that
#   would have to start THAT after a reboot is Task Scheduler - so it is Task
#   Scheduler, with nothing of ours in the middle.

# Later — the HTTP endpoints. Still deliberately deferred: nothing running
# locally needs them, and they are a deploy-time concern.
# fastapi>=0.110.0
# uvicorn[standard]>=0.29.0
